# Fig. 2d 强耦合误差检查与中心化作业

参数：`L=4, nelec=(2,2), t=-1, U=4, omega=0.5, alpha=4,
g=sqrt(2)`；每个声子模式分别保留 `0,...,Nmax`。

## 独立检查的设计

验证脚本为 `scripts/audit_fig2d_cutoff.py`，不修改学生的 `src`。

1. 用 Python bit string 直接计算电子产生、湮灭符号，独立生成 36×36
   电子 hopping 矩阵；用局域占据直接构造 Hubbard 对角元。
2. 用数组切片和 `sqrt(n)` 直接作用声子梯算符，不调用学生的局域算符、
   形状、构型枚举或 contraction 来生成参考算符。
3. 对归一化随机向量逐项比较学生实现，并检查总算符、对角元及双线性
   Hermiticity。随机比较是数值抽查，不是逐矩阵元证明。
4. 与 PySCF `direct_ep` 总算符比较时，将它减去的均匀力
   `g*(Ne/L)*sum_i(b_i+b_i†)` 加回。这里恢复的是算符，不能用能量常数
   替代；这样三套实现才使用完全相同的有限未中心化基底。
5. 使用独立参考算符和 SciPy `eigsh(which='SA')` 从随机初值求最低本征态，
   排查学生 Davidson 初值、预条件器或错误本征态问题。分别用参考算符和
   学生算符计算所得本征态的 residual。

运行：

```bash

  /home/enovo/.venvs/mr_lf/bin/python -m scripts.audit_fig2d_cutoff --nmax 16
```

## 不依赖项目程序的截断误差证据

先关闭 hopping。固定单站点电子占据 `n=0,1,2`，只需对角化

\[
h_n=\omega b^\dagger b+gn(b+b^\dagger).
\]

在未截断空间中，由配方得到最低能量

\[
e_n(\infty)=-g^2n^2/\omega=-4n^2.
\]

在 `Nmax=16` 时，直接对角化 17×17 实对称三对角矩阵，得到

| 电子占据 n | 无限声子空间 | Nmax=16 |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| 1 | -4 | -3.991419598557 |
| 2 | -16 | -13.123284411112 |

四电子分布只有三种占据类型：1111、2110 和 2200。
它们的原子极限能量分别是

\[
4e_1,\quad U+e_2+2e_1,\quad 2U+2e_2.
\]

因此未截断原子极限基态能量是 `-24`，Nmax=16 的原子极限基态能量是
`-18.246568822224`，仅声子截断就造成 **5.753431177776** 的误差。
这不意味着开启 hopping 后的误差必定等于此值，但已定量证明这种量级
可以由截断产生。

还有一个适用于完整 hopping 模型的下界：四格点 hopping 单粒子谱是
`(-2,0,0,2)`；每个自旋有两个电子，所以四电子 hopping 的最低能量为 `-4`。
对任意同一截断空间中的归一化波函数，都有

\[
E_{16}\ge E_{\mathrm{atomic},16}+E_{\mathrm{kinetic},\min}
=-22.246568822224.
\]

另一方面，无限声子空间中的局域 2200 电子态与相应相干态的乘积，是
完整 Hamiltonian 的合法试探态。它的 hopping 期望值为零，能量为 `-24`，
故真实基态满足 `E_exact <= -24`。因此即使不读取论文图，已经有

\[
E_{16}-E_{\mathrm{exact}}\ge 1.753431177776.
\]

这是截断空间本身的限制，改进本征值求解容差无法消除。

## 本轮唯一核心编码作业：中心化耦合 contraction

保留现有未中心化接口，新增：

```python
def contract_ep_centered(g, psi_site, L, nelec, Nmax):
    ...
```

数学定义：

\[
H_{ep,c}=g\sum_i(n_i-\bar n)(b_i+b_i^\dagger),\qquad
\bar n=(N_\alpha+N_\beta)/L.
\]

维数与数据流：

- `g`：有限实数标量；`nelec=(Nalpha,Nbeta)`。
- `psi_site` 和返回数组：`(nstra,nstrb)+(Nmax+1,)*L`，
  `nstr_sigma=C(L,Nsigma)`；输出 dtype 能容纳输入的实数或复数。
- 原始站点电子占据数组：`(nstra,nstrb,L)`。
- 每个元素减去同一个标量 `nbar`，形成涨落占据数组。
- 第 i 个电子占据对应声子轴 `2+i`；电子部分仍是两个 determinant address。
- 数据流：bit string → 局域占据 → 减平均占据 → 广播乘波函数 →
  对相应声子轴作用 `b+b†` → 乘 g 并累加。
- 半填充时原始占据 `0,1,2` 必须变成 `-1,0,1`。
- 这里不能把 nbar 换成当前波函数的逐站点平均密度；后者涉及另外的
  非均匀位移及附加一体项。

验收条件：

1. `g=0` 或 `Nmax=0` 时输出为零。
2. `L=2, nelec=(1,1), Nmax=1`，电子顺序为 `00,01,10,11`。
   原始两个站点占据矩阵为 `diag(2,1,1,0)`、`diag(0,1,1,2)`；
   中心化后必须为 `diag(1,0,0,-1)`、`diag(-1,0,0,1)`。
   与这些矩阵及局域声子 X 矩阵的 Kronecker 积逐元素比较。
3. 任意随机输入应满足
   `paper(psi)-centered(psi) = g*nbar*sum_i X_i psi`，包括复数输入。
4. 半填充且每站点恰有一个电子的 determinant，其 centered 耦合作用为零。

完成此原语后再接入总 Hamiltonian 和求解器。本轮不用提前修改这些接口。
之后求出的中心化 Hamiltonian 能量，通过

\[
E_{\mathrm{paper}}=E_c-\alpha N_e^2/L=E_c-16
\]

换回论文约定；必须单独记录这个常数，避免重复减去。
它对应先作无限空间中的声子位移再截断；不能要求两个有限截断谱恰差 16。

## Review 中的其他限制

`contract_1e`、`contract_2e_hubbard` 和 `contract_all` 的实数输出分配，
尚不能普遍支持复数波函数；本次实数模型计算不受影响。
`kernel` 丢弃了 `davidson1` 的 convergence flag；扫描脚本另行检查了 residual。
这些是后续接口完善事项，不能据此解释本次约 5 的能量差。
